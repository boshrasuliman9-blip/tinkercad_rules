زر الضغط — Push Button 🔘

وصّل زر الضغط والـ LED — عند الضغط على الزر يضيء المصباح

⏱ 15 دقيقة ⭐ متوسط 🔧 6 مكونات
المكونات المطلوبة
١
Arduino UNO — العقل الذي يتحكم في الدائرة
٢
Breadboard — لوحة التوصيل بدون لحام
٣
Push Button — زر الضغط
٤
LED — المصباح الضوئي
٥
مقاومة 220Ω — لحماية LED
٦
مقاومة 10kΩ — لزر الضغط (pull-down)
الخطوة ١ من ٤

ضع المكونات على البريدبورد

ضع زر الضغط في منتصف البريدبورد بحيث يمتد على الفجوة الوسطى. ضع LED بجانبه، واربط المقاومة 220Ω مع الطرف الطويل للـ LED.

الخطوة ٢ من ٤

وصّل زر الضغط

طرف زر الضغط الأول → 5V في Arduino.
الطرف الثاني → Pin 7 + مقاومة 10kΩ إلى GND.

⚠️ تأكد من وضع المقاومة pull-down لتجنب قراءات خاطئة
الخطوة ٣ من ٤

وصّل الـ LED

الطرف الطويل (+) للـ LED → مقاومة 220Ω → Pin 13.
الطرف القصير (-) → خط GND.

الخطوة ٤ من ٤ — مرجع الأسلاك

جدول توصيل الأسلاك

5V (Arduino)
← طرف زر الضغط
Pin 7 (Arduino)
← الطرف الثاني للزر
GND (Arduino)
← مقاومة 10kΩ + (−) LED
Pin 13 (Arduino)
← مقاومة 220Ω ← (+) LED

افتح Code Editor داخل Tinkercad (أعلى يمين المحاكاة) واختر نوع الكود Text، ثم الصق الكود التالي: 

// زر الضغط — Push Button Challenge
const int buttonPin = 7;
const int ledPin    = 13;

void setup() {
  pinMode(buttonPin, INPUT);
  pinMode(ledPin,    OUTPUT);
}

void loop() {
  int state = digitalRead(buttonPin);

  if (state == HIGH) {
    digitalWrite(ledPin, HIGH); // شغّل LED
  } else {
    digitalWrite(ledPin, LOW);  // أطفئ LED
  }
}
شرح الكود
١
setup() — تُحدد أن Pin 7 مدخل (زر) وPin 13 مخرج (LED)
٢
digitalRead() — تقرأ حالة الزر: HIGH = مضغوط، LOW = غير مضغوط
٣
digitalWrite() — تُشغّل أو تُطفئ الـ LED بناءً على حالة الزر
💡 اضغط Start Simulation ثم اضغط على الزر في الدائرة — يجب أن يضيء الـ LED عند الضغط
