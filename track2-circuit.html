البرمجة
⏱ 5 دقائق 🔒 مقفلة
📋

افتح Code Editor داخل Tinkercad (زر أعلى يمين المحاكاة)، اختر نوع الكود Text، ثم احذف الكود الموجود والصق الكود التالي:

blink.ino 
// أول دائرة — LED يومض كل ثانية
const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH); // شغّل LED
  delay(1000);                  // انتظر ثانية
  digitalWrite(ledPin, LOW);  // أطفئ LED
  delay(1000);                  // انتظر ثانية
}
شرح الكود سطراً سطراً
١
pinMode(ledPin, OUTPUT) — يُحدد أن Pin 13 مخرج لإرسال الكهرباء للـ LED
٢
digitalWrite(HIGH) — يُرسل 5 فولت إلى Pin 13 فيضيء الـ LED
٣
delay(1000) — ينتظر 1000 ميلي ثانية = ثانية كاملة بدون تغيير
٤
digitalWrite(LOW) — يوقف الكهرباء عن Pin 13 فيطفأ الـ LED
💡 اضغط Start Simulation في Tinkercad — يجب أن يبدأ الـ LED بالوميض كل ثانية تلقائياً
🎯
تحدي إضافي: غيّر الرقم 1000 إلى 200 — ماذا يحصل للـ LED؟ ثم جرّب 50. لاحظ الفرق!
